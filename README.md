# UQCS Competitive Programming Group
A subgroup of the UQ Computing Society, named UQCS Competitive Programming Group (CPG), run contests each week and this repo is a place to store and show my solutions to each weeks questions. 

## Structure
As guessed, you can find `x` weeks solutions in the folder named `weekx`. Inside these folders you will find my solutions, Python files, with the file name to identical to HackerRank questions (ones provided by CPG for that week). To have more context on a solution (what the question actually is) just search the name of the file and click the appopraite HackerRank question.
